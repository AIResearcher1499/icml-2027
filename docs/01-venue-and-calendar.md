# Venue and calendar

Last updated: 2026-08-28.

## Decision already taken

**Primary: ICML 2027.** ACL 2027 is the fallback if the paper is written and ICML is a miss on *fit*, not the design target.

Rationale (prestige vs fit, for this author):

- Google Scholar Metrics 2025 (articles 2020–2024): ICML h5 **272** / median 471; ACL h5 **236** / median 387. NeurIPS 371, ICLR 362 sit above both.
- Jurgens (arXiv:2607.02416): NLP-topic papers at general-ML venues get an estimated **+75%** citations vs content-matched *ACL papers; **within-author +118%**.
- CCF A and CORE A* for both. Difference is audience, not a rank-class gap.
- For an NLP measurement paper, ACL reviewers understand the object better. For option value (labs, portable CV, citation), ICML is the better single bet **if the paper can carry an ICML voice**.
- A weak ICML reject that then misses ACL 2027 is worse than a clean ACL Main. Hence: write the ICML argument; keep an ACL abstract in reserve; do not dual-submit.

## Dual submission — ICML vs *ACL

ARR forbids a paper under review at ICML/NeurIPS/etc. ICML forbids a paper under review at another archival conference.

| Path | Timeline | Notes |
|---|---|---|
| ICML-only | Submit ~Jan 2027 | Default. |
| ARR October 2026, **do not commit** NAACL | Reviews ~18 Dec 2026; cycle end ~20 Dec; then ICML Jan | Legal only if the ARR cycle has ended before the ICML full-paper deadline. Use only if a draft is already ready in October. |
| ARR January 2027 → ACL 2027 | Conflicts with ICML January | Pick one. |
| ICML reject (~May 2027) | Too late for ACL 2027 commit (~April 2027) | Next *ACL is EMNLP 2027; next ML is NeurIPS 2027 (~May). |

NAACL 2027 (ARR 12 Oct 2026, commit 23 Dec 2026) is a top NLP venue but is **not** the stated target.

## How to write the same numbers for two venues

Do not write two papers. Write the experiments first.

- **ICML voice:** one assumption → intervention → where the computation lives. Few datasets, many controls.
- **ACL voice (fallback abstract):** generated text as a bad witness; typology + protocol.

Same tables. Two abstracts, written last.
